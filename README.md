# OS-Deadlock-Analysis
Deadlock Analysis and Resource Allocation Dashboard

📌 Project Overview

The Deadlock Analysis and Resource Allocation Dashboard is an interactive web-based application developed using Python and Streamlit.

The project demonstrates important Operating System concepts related to deadlock management, resource allocation, and process execution. It helps users understand how resources are allocated among processes and how deadlock situations can be analyzed and handled.

🎯 Objectives

Understand deadlock concepts in Operating Systems.

Implement Banker's Algorithm for deadlock avoidance.

Calculate the Need matrix automatically.

Identify safe and unsafe system states.

Analyze resource requests.

Demonstrate deadlock detection and prevention.

Explore deadlock recovery techniques.

🚀 Features

Interactive web-based dashboard.

Resource allocation and process configuration.

Automatic Need matrix calculation.

Banker's Safety Algorithm.

Safe sequence identification.

Resource request analysis.

Deadlock detection and prevention.

Input validation and test-case analysis.
